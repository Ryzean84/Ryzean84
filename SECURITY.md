# Security Policy

## Scope

This repository is intended for lawful, authorized research and defensive use. Use only systems, datasets, and services for which you have permission.

## Reporting

Do not publish exploitable details or sensitive data in public issues. Contact the repository owner through the private contact method listed on the GitHub profile, with a concise description, impact, reproduction steps, and a safe disclosure timeline.

## Handling

- Do not commit credentials, tokens, private keys, personal information, or raw sensitive intelligence.
- Apply least privilege and data minimization.
- Treat unverified findings and generated output as untrusted until independently validated.
- Security claims must be supported by evidence; this policy is not a certification.
